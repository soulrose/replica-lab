Replica Lab พร้อมแล้ว เพิ่มแอปแรกเพื่อเริ่มรันเป็นหลาย replica ได้จาก

  • จาก image ในเครื่อง ที่ build หรือ pull ไว้แล้ว เลือก image แล้วฟอร์มกรอกค่าให้เอง

  • หรือ ควบคุม service ที่รันอยู่ใน swarm แล้ว

สิ่งที่มีในเวอร์ชันนี้

  

  
หลักเลขเวอร์ชัน: แก้บั๊ก = เลขท้าย (1.0.1), เพิ่มความสามารถ = เลขกลาง (1.1.0), เปลี่ยนแบบที่ของเดิมใช้ไม่ได้ = เลขหน้า (2.0.0) อัปเดตไม่แตะ config\ และ apps\*.local.env และไม่ทับโปรไฟล์แอปที่มีอยู่







  
แอปรันได้ทีละแอป สลับแล้วแอปเดิมหยุดและจำค่าไว้

  

  

  
service ที่รันอยู่ใน swarm ของเครื่องนี้

  
service ที่ไม่ได้สร้างจาก Replica Lab กด ควบคุมเลย เพื่อปรับจำนวน replica, เริ่ม/หยุด, ดู log และยิงทดสอบกับ service นั้นตรงๆ (ใช้ port เดิมของมัน ปิด Replica Lab แล้ว service ยังรันต่อ) หรือ คัดลอกเป็นแอปใหม่ เพื่อรันอีกชุดจากค่าของมัน (ต้องใช้ port อื่น)

  

  

  
สร้าง image จากโฟลเดอร์โปรเจกต์

  
วาง path ของโปรเจกต์ที่มี Dockerfile แล้วกด Build ได้ image ในเครื่อง จากนั้นฟอร์มเพิ่มแอปด้านล่างจะกรอกให้เอง

  

    
    
    
  

  

    
    
  

  

  

    
    
    
  

  

  

  

  
เพิ่มแอปจาก image ในเครื่อง

  
ทีม build image ไว้ในเครื่อง (docker build) แล้วเลือกที่นี่ ค่าจะถูกใส่ให้ทันที (ชื่อตาม image, port 8080, RAM อัตโนมัติ) แล้วปรับให้แม่นขึ้นจาก LABEL rama.lab.* หรือหน้าตา image (Tomcat/WAR, Spring Boot) แก้ได้ก่อนบันทึก
